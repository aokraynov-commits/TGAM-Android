# TGAM Monitor

Приложение для работы с нейроинтерфейсом **NeuroSky MindWave** (чип TGAM):
читает данные внимания (Attention) и медитации (Meditation) из COM-порта
и управляет курсором мыши по этим значениям.

## Структура проекта

```
tgam_monitor/            # пакет приложения
├── __init__.py          # публичный API пакета
├── parser.py            # парсер протокола TGAM (конечный автомат, без UI-зависимостей)
├── mouse.py             # чистая логика движения курсора и индикатора (тестируется без pyautogui)
└── app.py               # GUI на tkinter + чтение последовательного порта (SerialReader)
tgam_monitor4.py         # точка входа (совместимость с оригинальным запуском)
tests/                   # pytest-тесты парсера и логики мыши
```

## Реконструкция

Код восстановлен из вложения `tgam_monitor4.py.msg` (письмо от 05.03.2026) —
оригинал сохранён как `original_tgam_monitor4.py`. Единый файл разбит на модули:

| Было (монолит)              | Стало                                  |
|-----------------------------|----------------------------------------|
| `TGAMSimpleParser`          | `tgam_monitor.parser.TGAMParser`       |
| потоковое чтение порта в `MindWaveMonitor.read_serial` | отдельный класс `tgam_monitor.app.SerialReader` |
| `move_mouse_*`, `update_indicator` внутри GUI | чистые функции `tgam_monitor.mouse` (инъекция `mover`) |
| константы «в коде»          | именованные константы (`SYNC_BYTE`, пороги зон и т.д.) |
| магические числа 25/50/75/10| `DISCRETE_BOUNDARIES`, `CONTINUOUS_MAX_STEP` и пр. |

Поведение приложения полностью совместимо с оригиналом; добавлены type hints,
docstrings, разделение ответственности и тесты.

## Установка и запуск

```bash
pip install -r requirements.txt
python tgam_monitor4.py
```

Требуется Python 3.8+ с tkinter; для Windows — порт вида `COM5` (9600 бод).

## Тесты

```bash
pytest
```

## Управление курсором

- **Дискретный режим**: внимание 0–25 → вверх, 26–50 → вниз, 51–75 → влево, 76–100 → вправо (шаг 10 px на пакет).
- **Непрерывный режим**: внимание смещает курсор по Y, медитация — по X (шаг пропорционален отклонению от 50, ограничен ±10 px).
